# Архитектура

## Поток данных

1. **Приём (ingest).** Фид читается соответствующим парсером (`tip/feeds`). Каждый парсер
   наследует `Feed` и реализует `parse(text) -> Iterator[Indicator]`. Нераспознанные строки
   пропускаются, а не роняют загрузку.
2. **Нормализация и дедуп.** `tip/normalize` приводит значение к канону (lowercase доменов и
   хешей, сжатие IPv6, refang), определяет тип и схлопывает дубликаты по ключу `(тип, значение)`.
3. **Хранение.** `Storage` (SQLite) выполняет upsert с объединением метаданных существующего
   индикатора (окно наблюдения, теги, максимум доверия).
4. **Обогащение (enrich).** `enrich_and_score` прогоняет каждый индикатор через подходящие
   обогатители. Результат — список `Enrichment` (по провайдеру), сохраняется в БД.
5. **Скоринг.** `ScoringEngine` складывает вклад типа, доверия источника, тегов и обогащения,
   ограничивает результат диапазоном 0–100 и присваивает уровень критичности.
6. **Корреляция.** `correlate` строит граф связей (общие теги, общий IP из резолюции) и
   выделяет компоненты связности через union-find.
7. **Матчинг.** `IocMatcher` извлекает индикаторы из произвольного текста и сверяет с базой,
   формируя алерты с учётом порога критичности.
8. **Выдача.** REST API (`tip/api`) и генератор отчётов (`tip/report`).

## Ключевые модели (`tip/models.py`)

- `Indicator` — нормализованный IOC с метаданными и методом `merge` для дедупликации.
- `Enrichment` — результат одного провайдера обогащения.
- `Score` — балл риска, уровень и список причин.
- `Alert` — срабатывание матчинга.
- `ThreatCluster` — группа связанных индикаторов.

## Расширение

- **Новый фид:** наследовать `Feed`, реализовать `parse`, зарегистрировать в
  `tip/feeds/__init__.py:FEED_FORMATS`.
- **Новый обогатитель:** наследовать `Enricher`, задать `supports` и реализовать `enrich`.
- **Реальный провайдер репутации:** реализовать протокол `ReputationProvider` (метод `check`)
  поверх HTTP-клиента и передать в `ReputationEnricher`.

## Схема БД

```
indicators(value, type, source, first_seen, last_seen, confidence, tags, raw)  PK(type, value)
enrichments(value, provider, data, ts)                                          PK(value, provider)
scores(value, score, severity, reasons)                                         PK(value)
alerts(ts, value, type, severity, source, context)
```
